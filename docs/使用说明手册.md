# FRU 自动化工具 — 使用说明手册

**产品：** FRU 自动化整合工具（FruTool）  
**适用版本：** 5.5.0  
**适用对象：** 现场硬件运维（BMC / FRU / 换板 / PCIe 拓扑）

**图文版教程（含界面截图）：** [使用教程手册.md](使用教程手册.md) · 网页 [使用教程手册.html](使用教程手册.html) · PDF [使用教程手册.pdf](使用教程手册.pdf)


---

## 1. 产品定位

FruTool 是 **多功能** 现场工具，不是单一流水线。四个模块可按任务独立使用：

| 模块 | 作用 | 与其它模块关系 |
|------|------|----------------|
| **连接与网络** | 网卡、DHCP、旧/新板凭据、BMC 在线状态 | **唯一公共前提**：凡访问 BMC 必先配好 |
| **换板流程** | 旧板 FRU 备份 → 换板 → 克隆并还原 SN | 与 FRU/拓扑无强制先后 |
| **FRU 字段刷写** | 当前板字段级读写 | 与换板不同：非整包身份迁移 |
| **PCIe 拓扑刷写** | 拓扑 `.bin` → EEPROM 0x7E00 | 可单独做，也可换板后再做 |

```text
          ┌─→ 换板流程
连接就绪 ─┼─→ FRU 字段刷写
          └─→ PCIe 拓扑刷写
```

## 2. 开始之前

### 2.1 运行环境

- Windows 10 / 11
- 首次启动会请求 **管理员权限**（UAC），用于本机网卡与 DHCP 等操作
- 需要能访问目标服务器 BMC 网络（通常为本机网线直连或同网段）

### 2.2 如何启动

**打包版（推荐现场使用）**

1. 解压或拷贝整个 `FRUTool` 文件夹到本机（不要只拷单个 exe）
2. 双击 `FRUTool.exe`
3. 同意 UAC 提权

**开发版**

```powershell
python fru_tool.py
```

### 2.3 目录与可覆盖资源

以 `FRUTool.exe` 所在目录为根：

| 路径 | 说明 |
|------|------|
| `FRUTool.exe` | 主程序 |
| `_internal/` | 打包内置资源（勿随意删） |
| `ipmitool/` | **可覆盖**：ipmitool / 拓扑脚本 |
| `PCLE/` | **可覆盖**：PCIe 拓扑压缩包库 |
| `fru_backup/` | 运行后生成：FRU 备份、换板会话 |
| `logs/` | 运行后生成：按日日志、拓扑索引与脚本偏好 |

更换 ipmitool 或拓扑脚本时，放到 **exe 同目录的 `ipmitool/`**，无需重新打包。

## 4. 第一步（唯一公共）：连接与网络

凡 FRU 刷写、换板、拓扑，只要访问 BMC，都先完成本页。配好后可随意切换其它模块，无需按固定顺序「走完所有功能」。

### 4.1 本页内容

| 区域 | 说明 |
|------|------|
| 连接状态 | 本机、BMC 是否就绪 |
| 旧板凭据 | 旧主板账号/密码（换板读旧板常用） |
| 新板凭据 | 新主板账号/密码（**拓扑与多数写操作默认用这一组**） |
| 显示密码 | 核对密码 |
| 本机 IPv4 / 刷新网卡 | 选择连 BMC 的网卡 |
| 摘要 | BMC 将分配地址等提示 |

### 4.2 操作步骤

1. 接好网线（直连 BMC 或同网段）。
2. 填写旧板、新板账号密码。
3. 选择本机网卡，必要时 **刷新网卡**。
4. 工具按网卡情况自动处理内置 DHCP（一般无单独开关）。
5. 等待「本机与 BMC 均已就绪」后再做其它功能。

### 4.3 注意

- 网卡若为 Windows DHCP 客户端，内置 DHCP 可能不启动，请按机房规范改静态。
- 拓扑页使用 **新板账号密码 + 当前 BMC IP**。

下列三章 **无强制先后**。连接就绪后点侧栏对应入口即可。

## 6. 换板流程

### 6.1 功能说明

将旧板 FRU 身份备份并写入新板，处理 Board Serial 等字段。支持手动 / 自动、跳过已有备份的步骤 1、克隆前新板原始备份与回滚。

顶部可切换 **手动 / 自动**，必要时 **重置进度**。

### 6.2 备份命名（`fru_backup/`）

| 类型 | 命名示例 | 说明 |
|------|----------|------|
| 工具导出 | `SN123_20260820_2047.bin` | `{SN}_时间戳.bin` |
| 手导 / 投放 | `SN123.bin` | `{SN}.bin`，同样识别 |
| 新板原始 | `SN123_NEW_ORIGINAL_时间戳.bin` | 克隆前另存，供回滚 |

填入 SN 后若已有匹配备份 → **可跳过步骤 1**，直接步骤 2。

### 6.3 手动流程

1. BMC 在线，模式选手动。
2. 填 **旧服务器 SN** → **导出 FRU 备份**（连旧板时执行）。
3. 物理换板，确认新板 BMC 在线（密码/网卡无误）。
4. **克隆 FRU 并还原 SN**。
5. 异常时用 **回滚新板原始 FRU**。

### 6.4 自动流程

1. 切换自动。
2. BMC 上线 → 读 FRU → 弹窗核对 SN。
3. **确认并导出** 或 **取消**（Product Serial 为空不能自动继续）。
4. 等旧板离线 → 新板上线 → 自动克隆。
5. 写入中勿强制结束程序。

## 7. FRU 字段刷写

### 7.1 功能说明

对 **当前在线 BMC** 做字段级读写（Chassis / Board / Product），不是整包换板。空字段不会被刷写。

### 7.2 操作步骤

1. 连接就绪。
2. 进入 FRU 页 → **尝试读取 FRU**（若尚未有数据）。
3. 编辑需要的字段。
4. **刷写所有非空字段**；日志看 **FRU** 标签。
5. 放弃编辑用 **重置**。

**与换板区别：** 换板 = 旧板整包身份迁到新板；本页 = 当前板字段微调。

## 8. PCIe 拓扑刷写

### 8.1 功能说明

将拓扑 `.bin` 写入 EEPROM（0x7E00）。含：刷写区、按 FRU 套餐号的 **匹配套餐拓扑**、可筛选的 **PCLE 拓扑库**；支持多版本脚本下拉与记忆。

### 8.2 选择拓扑脚本

1. **拓扑脚本** 下拉选择 `PcieEEpromTool*.py`；**刷新** 重新扫描。
2. 扫描范围：exe 旁、`ipmitool/`、打包内置；偏好写入 `logs/topo_prefs.json`。
3. **执行约束：** 脚本须在 `ipmitool/` 下运行。其它位置选中时，刷写前加载为 `ipmitool/PcieEEpromTool_run.py`（不覆盖主脚本）。
4. 现场建议多版本直接放在 exe 旁 `ipmitool/`。

### 8.3 选择拓扑 .bin

任选其一：

- **浏览** 本地 `.bin`（通常 ≤ 512 字节）
- **匹配套餐拓扑** 卡片（可含「推荐」）
- **PCLE 拓扑库** 按厂商 / 机型 / 套餐 / 包名筛选后点选

### 8.4 开始刷写

1. BMC 在线，脚本与 `.bin` 已选。
2. **开始刷写拓扑文件**（新板账号密码 + 当前 BMC IP）。
3. 结果见终端 **拓扑** 标签。

PCLE 库放在 exe 旁 `PCLE/` 即可覆盖内置。打包版需本机 Python（`python` / `py -3`）可用。

## 9. 场景速查

| 目标 | 模块 |
|------|------|
| 只换主板、迁移 FRU 身份 | 换板 |
| 只改几个 FRU 字段 | FRU 字段刷写 |
| 只刷拓扑 | PCIe 拓扑刷写 |
| 换板后再刷拓扑 | 先换板再拓扑（连接配一次即可） |
| 已有 `{SN}.bin` 写新板 | 换板填 SN → 跳过步骤 1 → 克隆 |

## 11. 常见问题

| 现象 | 处理建议 |
|------|----------|
| BMC 一直离线 | 网线、网卡、账号密码、管理员权限 |
| 拓扑刷写失败 | 脚本是否在 `ipmitool/`；`.bin` 大小；拓扑日志；本机 Python |
| 找不到拓扑脚本 | 放入 `ipmitool/`，点刷新 |
| 换板找不到备份 | SN 与 `fru_backup` 中 `{SN}.bin` / `{SN}_时间戳.bin` 一致 |
| 误关程序 | FRU/拓扑写入中勿强制结束 |

---

## 12. 安全与注意

- 仅在授权设备上使用；勿随意外传 `logs/`、`fru_backup/`
- 换板与拓扑会改非易失数据，操作前确认 SN、机型与拓扑版本
